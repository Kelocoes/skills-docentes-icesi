# Universidad Icesi Brand Color Definitions

Official institutional color palette for Universidad Icesi documents, syllabi, workshops, and assignments.

---

## Primary Palette

### Azul Icesi (Primary Institutional Blue)
- HEX: `#5454E9`
- RGB: `rgb(84, 84, 233)`
- CMYK: `C:70 M:65 Y:0 K:0`
- LaTeX Definition:
  ```latex
  \definecolor{icesiBlue}{HTML}{5454E9}
  ```

## Institutional Multi-Color Stripe (Header Signature)

The multi-color segmented stripe displayed underneath headers consists of:
1. Azul Icesi (`#5454E9`): 65% width
2. Naranja Icesi (`#E9683B`): 15% width
3. Verde Icesi (`#4CB979`): 10% width
4. Lavanda Icesi (`#CECDFD`): 10% width
